## 視点
- React + Vite / Netlify 自動デプロイ構成。フロントの本体は `src/App.jsx`。
- 「体感速度」と「初動の軽さ」は UX 品質に直結する。数字（CI結果）から体感への影響を翻訳する。
- 調べて終わりにせず、各所見に理由と、再現・修正の具体手順（改善提案）を付ける。
- 大規模リファクタは提案しない。まず計測、次に最小の修正。
