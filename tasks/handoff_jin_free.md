## 実行手順

### 0. 事前確認 → 済
- 単品500円の売上：**0円**（俊雄さん確認 2026-09-23）。RESOLVED_FACTS にこの事実を記録すること。

### 1. 現状スナップショット（ロールバック用）
```
python -X utf8 scripts/investigate_paywall.py > var/jin/snapshot_before_free_2026-09-23.txt
```
＋ 56本の `name / price / status / reserved_publish_at / body` を JSON で `var/jin/bodies_before_free/` に保存（本文はここから復元できるようにする）。

### 2. 価格を0にする（1本テスト → 全件）
**API PUT は使わない**（`/api/v1/text_notes/{id}` は本文を送らないと422、本文を送ると別の422。lessons.md 2026-05-11節）。

Playwright で editor の公開設定画面を操作する。`scripts/set_jin_payline.py` の `set_one()` と同じ骨格：
1. `/edit/` を開く → wait 7秒（本文のUUID正規化を待つ）
2. 「公開に進む」
3. 記事タイプ「**無料**」ラジオを選択（recon済のDOM：`記事タイプ` セクション内の `無料` ラジオ）
4. 保存：**published記事＝「更新する」／reserved記事＝「予約投稿」**（ボタン名が違う。取り違えるとtimeout）
5. 検証：`/api/v3/notes/{key}` で `price==0`、かつ **認証なしGET** で `can_read==True` と本文全文が返ること（reservedは公開前なのでanonで見えない＝priceだけ検証）

まず **jin_03 で1本**。無事なら残り55本をバッチ。各記事ごとに検証し、失敗はリストして最後に再試行（1回で通らないことがある＝lessons 2026-05-11「PUT 200でも反映されない不安定症状」）。

### 3. 本文末尾のメンバーシップCTAを置換（56本）
jin_の本文末尾には次のブロックがある（jin_03で確認済み）：
```
このシリーズでは、職場にいる「困ったあの人」を心理学で攻略する処方箋を定期配信しています。メンバーシップに入ると全記事が読み放題になります。
👉 対人攻略シリーズ・メンバーシップはこちら（https://note.com/lifeoraclejp/membership）
```
これを標準末尾CTAに置換する。**本文編集は最も壊れやすい作業**なので：
- 置換対象のパターンを正規表現で厳密に定義し、**該当しない記事は触らない**（ログに出す）
- 手段は Playwright editor での本文編集ではなく、`pipeline/thin_lib_htmlaware.py` 系の「該当ブロックだけ差し替えて PUT → verify」パターンを優先（yoru/post の読点是正で実証済み・バックアップ内蔵）。ただし jin_ で PUT が通るか **1本で確認してから**。通らなければ Playwright editor で本文末尾を直接編集。
- 置換後、本文の文字数差分が「置換ブロックの差分」と一致することを検証（他が変わっていないこと）
- **2.の価格変更と同じPUT/保存に相乗りできるなら1回で済ませる**（保存回数を減らす）

### 4. メンバーシップの終了
**2.の全56本 price=0 が完了してから**行う（記事とプランの紐付けが残ったまま終了すると挙動が読めないため、順序を守る）。
1. `/api/v2/circle/memberships/summaries` で totalCount==0 を再確認
2. `https://note.com/membership/settings` → 「管理画面を開く」→ メンバーシップの終了（解除）。パスワード再認証を求められたら**そこで止めて俊雄さんに操作を依頼**（Sonnetは認証情報を入力しない）
3. 終了後の検証：`/api/v2/creators/lifeoraclejp/circle` が 404 になるか `isCirclePublished:false` になること。`/api/v3/memberships/circle_permissions?note_key=<jin_03のkey>` の結果も記録
