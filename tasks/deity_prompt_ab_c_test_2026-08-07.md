## C案（構造から再設計・約620字）

変えた点は4つ。
1. **描画する日本語テキストを6ブロック→3ブロック**（神名・神徳・一言）に削減。
   画像生成AIは日本語の文字描画が最も苦手で、ブロック数が崩れの主因になる。
2. **人物像を"語り"から"視覚の指示"に翻訳**。praise/habit の長文をそのまま渡さず、
   絵に落ちる言葉（姿勢・持ち物・光の当たり方）に変換して渡す。
3. **性別の確認質問を封じる**。「確信が持てない場合のみ確認して」を削除し、
   推定できなければ中性的に描く、と指定。途中で質問が返って止まるのを防ぐ。
4. **処方箋・背景・バイアス説明を渡さない**。絵に効かないため。
   バイアス名だけは画像内テキストに残す。

```
あなたは日本の神を描く絵師です。以下の人物を「神」として1枚の縦長ポスター（2:3）に描いてください。

【人物】40代・会社員。私との会話やメモリから性別を推定して反映（推定できなければ中性的に）。説明文は書かず、画像だけを返すこと。

【神の姿】
・会社員の要素（背広の襟、書類、印章）を神衣・神器へ昇華させる。
・決断の瞬間に周囲が動き出す神。片手は前へ差し出し、視線はまっすぐ遠くへ。
・整いすぎた佇まいの中に、一箇所だけ緩んだ布や乱れた髪を置く（完璧さを手放す兆し）。

【画づくり】
・様式：荘厳でシネマティック、静謐、神話画の品格。戦闘感は出さない。高精細。
・光と色：アンバーゴールドの神光と深い藍の高コントラスト。逆光気味に。
・構図：中央に神。背景は御札・曼荼羅風の紋様。

【画像内に描く日本語（この3つだけ。明朝体・誤字なく）】
1. 神名：性格から荘厳に創作した名前（大きく上部に）
2. 神徳：「統べる」「decide」ではなく漢語で3語（例：統率／明断／実行）
3. 一言：短い神託を一文（例：握る手をひらけ）

文字は上記3ブロックのみ。他の説明文字は画像に入れないこと。
```

## 見るポイント

- **速度**：C が明確に速ければ「長さ」が原因。A も B も同程度なら「長さ」より「描く文字数」が効いている。
- **文字崩れ**：C の3ブロックで崩れが減るか。減るなら本番も3ブロックに寄せる。
- **絵の出来**：A と B の差＝処方箋1文の質。差が出るなら B（要約フィールドの追加）に投資する価値がある。
- **止まらないか**：A・B は性別確認で質問が返ってくることがある。C はそれを封じてある。

結果によって本番実装を決める。C が良ければ `buildDeityPrompt` を作り直す。
