## 0. この事典の思想（一番大事なこと）

**人の困りごとを「性格・能力のせい」に見えるところから、「構造・心理のせい」に翻訳し、名前(ラベル)を与える。** それがライフオラクルの核であり、相談員としてのあなたの武器。

- **名前を当てるのは目的ではなく入口**。「それは損失回避ですね」で終わると、相談者は分類されただけで終わる。名前は、その人と一緒に「秤を補正する／見えていない側を見る」作業に入るための扉。
- **決めるのは、いつも本人**。相談員の仕事は、本人が見落としている側を秤に乗せて「両方が見える状態」を渡すこと。動かすことでも、思いとどまらせることでもない。
- **「あるある」で止めない**。共感(そうそう)で終わらせず、解読(そういうことだったのか)まで運ぶ。感情語(不安・孤独)でなく、その感情が生まれる「瞬間の描写」で返す。

## 1. 相談現場での使い方（3ステップ）

### Step 1. 聞く → 兆候を拾う
相談者の話の「内容」より、**言い方・体の動き・主語の切り替わり・温度差**を見る。各エントリの「発現サイン」は、この瞬間を拾うためのチェックリスト。

### Step 2. 読む → どの効果が、どのタイプの影で出ているか
拾った兆候から該当バイアスを引く（下の逆引き索引）。各エントリの「認知機能(光と影)との関連」で、**同じバイアスでもこの人はどの方向に強いか**を補助線として読む。※タイプ当てゲームにしない。本人に型を告げる必要はない。

### Step 3. 返す → 問い → 声かけ → （NGを避ける）
各エントリの「問いの立て方」で本人に気づかせ、「声かけ例」でそのまま言葉にする。「NG」は、相談員自身が無意識にやりがちな失敗（=本人の自己嫌悪を深める対応）の回避リスト。

### 複数の効果が同時に出た時の優先順位
相談では2〜3個のバイアスが絡むのが普通。次の順で扱う：
1. **いま本人を最も苦しめている自己嫌悪に直結するもの**を先に（例：「自分が怠けている」と責めている→現在バイアス を先に外す）。
2. **「動けなさ」の根」になっているもの**を次に（損失回避・サンクコスト・現状維持は、他の悩みの土台になりやすい）。
3. **派生・表面のもの**は後回し。根が外れると派生は軽くなることが多い。
> 一度に全部名前を当てない。一つ外して本人の表情が緩んだら、その日はそこまで。

## 2. 逆引き索引（相談者の「困りごと」から効果を引く）

相談者は「バイアス名」では来ない。「困りごとの形」で来る。そこから引く。

| 相談者の訴え・場面 | まず疑う効果 |
|---|---|
| **動けない・先延ばし**（やらなきゃと分かってるのに） | 現在バイアス／プランニング誤謬／ツァイガルニク効果／現状維持バイアス |
| **手放せない・見切れない**（もったいない・今のままで） | 損失回避バイアス／サンクコスト効果／コミットメントと一貫性 |
| **決められない**（選択肢が多い・どれも怖い） | 選択の逆説／損失回避／FOMO |
| **自分を過大/過小に見る**（自信過剰 or 自信なさすぎ） | 過信バイアス／ダニング・クルーガー効果／自己奉仕バイアス／スポットライト効果 |
| **人を一面で決めつける**（あの人は○○だ） | 確証バイアス／基本的帰属錯誤／ハロー効果／内集団バイアス |
| **周りに流される・乗り遅れ不安** | 同調バイアス／社会的証明／バンドワゴン的同調／FOMO |
| **危険を軽く見る/重く見る**（自分は大丈夫 or 過剰に怖い） | 正常性バイアス／基準率の無視／ネガティビティ・バイアス／ノセボ効果 |
| **過去の評価がゆがむ**（あの時こうすれば・結果論） | 後知恵バイアス／結果バイアス／ピーク・エンドの法則／生存者バイアス |
| **言い方・最初の情報に縛られる** | アンカリング／フレーミング効果／利用可能性ヒューリスティック |
| **矛盾を正当化する・反発する** | 認知的不協和／心理的反発(リアクタンス)／ライセンシング効果 |
| **「自分は今日頑張ったから」と崩れる** | ライセンシング効果／現在バイアス |

> 兆候→効果が一意に決まらないのが普通。複数候補を持って、本人の言葉で絞り込む（各エントリの「発現サイン」で確認）。

## 3. 拡張・育て方

- **顧客対応版**：保険窓口の顧客（購入・意思決定）に向けて、同じ35効果の「顧客文脈の発現サイン・声かけ例」を足す（フレーミング・アンカリング・損失回避・社会的証明が特に効く）。今は従業員対応を優先。
- **業界特化版**：保険/金融特有の場面（更新・乗り換え・据置）への応用。流入・実務が育ってから。
- **現場で育てる**：実際の相談で「この声かけは響いた/外した」を各エントリの末尾にメモで追記していく。**推敲しながら自分の言葉にする**のが、この事典の本来の完成形。
- **記事との往復**：各効果はあなたの500+記事のどれかで既に深掘り済み。相談者に「もっと読みたい」と言われたら、該当記事(note)を渡せる（関連記事リンクは別途付与予定）。
