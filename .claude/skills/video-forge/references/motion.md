# モーション技法カタログ

コンセプトに詰まったらここから引く。**組み合わせるのは2〜3個まで**。全部盛りは散らかる。

前提：`src/lib/motion.js` の `useEnter` / `useStagger` / `useCount` / `useCamera`、
`src/lib/text.jsx` の `SplitText` を使う。

---

## A. 時間の技法

### A1. スタガー（時間差）
要素を同時に出さない。3〜8フレームずつずらすだけで「意図」が生まれる。
```jsx
const {opacity, y} = useEnter(20 + index * 6);
```
**注意**：`map()` の中で直接フックを呼ばない。要素は子コンポーネントに切り出す
（props で要素数が変わった瞬間にフック数が変わって壊れる）。

### A2. 溜めと解放
何も起きない時間（10〜20f）を先に作ると、その後の動きが強くなる。
全編びっしり動かすと、どこも見どころにならない。

### A3. 急停止
`spring` の `damping` を上げて（40〜200）ピタッと止める。
逆に `damping: 8〜14` は跳ねる＝軽い印象。**性格は数値で決まる。**

### A4. 拍（ビート）
30fps なら 15f = 0.5秒。要素の登場を拍に揃えると全体が締まる。
```jsx
const beat = Math.floor(frame / 15);
```

## B. 出現の技法（フェード以外の選択肢）

### B1. マスクで書き出す
文字や図形を「描かれていく」ように見せる。フェードより意志が強く見える。
```jsx
<div style={{clipPath: `inset(0 ${100 - progress * 100}% 0 0)`}}>{text}</div>
```

### B2. 線が引かれる（SVG）
```jsx
<path strokeDasharray={len} strokeDashoffset={len * (1 - progress)} />
```
図解・地図・グラフ・ブランドマークに効く。

### B3. 文字単位の分解
```jsx
<SplitText text="やめる" delay={20} per={2} />   // 1文字ずつ2フレーム差
```
日本語は1文字の情報量が大きいので、**単語単位より文字単位が効く**。ただし長文には使わない。

### B4. 遮蔽から出る
`overflow: hidden` の箱の中で `translateY` させる＝下から迫り上がる。
フェードと違い「そこに元からあった」感が出る。

## C. 意味を運ぶ技法（ここが差になる）

### C1. 数字が動く
金額・件数・年数は、**書くのではなく動かす**。
```jsx
const yen = useCount({from: 5876, to: 4386, start: 100, duration: 30});
<div>¥{yen.toLocaleString()}</div>
```
サブスクやめた系は特にこれが本命。実額が減るのを見せる以上の説得はない。

### C2. レイアウト転換（magic move）
同じ要素が役割を変える。「一覧の1行」→「主役の見出し」に変形させるなど。
`interpolate` で位置・サイズ・色を同時に動かす。**1本の動画に1回だけ使う。**

### C3. 反復と破れ
同じものを並べ、1つだけ違う動きをさせる。視線が必ずそこに行く。
「12ヶ月ぶんのアイコンが増殖 → 1つだけ止まる」など。

### C4. カメラを動かす
個々の要素ではなく画面全体を `scale`/`translate` する。寄る＝集中、引く＝全体像。
```jsx
const cam = useCamera({at: 90, scaleTo: 1.15, xTo: -80});
```

### C5. 実データの可視化
バーの長さ・面積・積み上げは金額と直結させる（`width: price / total * 100 + '%'`）。
**嘘の比率を作らない。**社会性＝正直さがブランドの必要条件（サブスクやめた憲法）。

## D. 画面設計

### D1. 1フレーム目を強くする
自動再生オフ・サムネ表示では 0f が全て。0f が真っ黒/真っ白なら設計ミス。
背景・ブランドマーク・最低限の文字は 0f から置く。

### D2. 縦型は上下1/6を捨てる
リール/ショートは上下に UI が被る。重要要素は中央 2/3 に収める。

### D3. 文字サイズの下限
1080幅なら本文 40px 以上、見出し 80px 以上。スマホで潰れる。

### D4. 色数
背景1・文字1・アクセント1の3色まで。ブランド色は `references/brand.md` から取る。

## E. やりがちな失敗

| 症状 | 原因 | 直し方 |
|---|---|---|
| 動いているのに退屈 | 全部が同じ速度・同じ方向 | 主役を1つ決め、他は遅く小さく |
| 情報が読めない | 要素の滞在時間が短い | 1要素あたり最低30f（1秒）は残す |
| 安っぽい | 装飾で動きを足している | 装飾を削り、意味のある動きだけ残す |
| どこかで見た | テンプレ埋めをした | Step 1 のコンセプト3案に戻る |
