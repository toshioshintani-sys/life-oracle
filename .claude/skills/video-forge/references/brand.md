# ブランド定義（動画で守るもの）

ここに書いてあるのは**プリセット2件**。このスキルはプロジェクト非依存なので、
ここに無いプロジェクトでも `references/new-project.md` の手順で作れる（色をリポジトリから拾う／
`neutral` で作る）。**プリセットの色を勝手に変えない・増やさない。**
実装（`subsuku-yameta-web/src/index.css` の `--hm-*` / `life-oracle/CLAUDE.md`）が変わったら
`src/lib/brand.js` を合わせる。

## サブスクやめた（`brand: 'subsuku'`）

| 用途 | 色 |
|---|---|
| 背景（濃） | `#2a3658` → `#141a2a`（グラデ） |
| 背景（淡） | `#faf6ee` |
| アクセント | `#34c0c6`（ティール） |
| 強調 | `#edb85f`（ゴールド） |
| 本文（淡背景時） | `#1b2030` |
| 損失・注意 | `#8f4326` / 背景 `#fbefe6` |

**トーン**：当事者が「やめた」を共有する語り口。運営が「やめさせる」ではない。

**禁則（憲法 §2-2 / §5）**：
- 煽らない（「損してます」「今すぐ」「絶対」）
- ランキング形式・★スコアを使わない
- アフィリエイト先が解約導線より目立つ画作りをしない
- 数字は実額のみ。比率・バーの長さを誇張しない（社会性＝収益の必要条件）
- 両論併記：サービスを薦める動画なら、短くてもデメリットに触れる

**効く題材**：実額の減少、解約の手数（ステップ数）、乗り換え後の差額、年間換算。

## ライフオラクル（`brand: 'oracle'`）

| 用途 | 色 |
|---|---|
| 背景 | `#faf6f1` → `#f1e9de` |
| 本文 | `#2d2318` |
| アクセント | `#b8833f`（アンバー） |
| アクセント濃 | `#8c5f28` |
| 光 | `#3d7a5a` ／ 影 | `#a05050` |

**シグネチャ**：羅針盤モチーフ。`src/lib/Mark.jsx` に実装済み。

**トーン**：ラベルを貼るのではなく「自分の動き方を理解する」。断定しない。内省的だが重くない。

**禁則**：
- 診断結果を決めつける言い方（「あなたは〜な人です」）
- 光と影の名前を変えない（Te=指揮者/鉄砲玉 … `life-oracle/CLAUDE.md` 参照）
- 煽り・不安訴求（「知らないと損」）

**効く題材**：光と影の対比（画面を2層に割る）、選択の分岐、バイアスの可視化。

## プリセットに無いプロジェクト

`neutral`（`src/lib/brand.js`）が既定。無彩色＋青系アクセントで、どのプロジェクトでも成立する。
その場のブランド定義を props で渡せば上書きできる（指定したキーだけ効く）：

```json
{"brand": {"bgFrom": "#101820", "bgTo": "#05070a", "accent": "#e0a34a", "name": "Foo", "url": "foo.dev"}}
```

同じプロジェクトで繰り返し作るなら `presets` に1件足す。手順は `references/new-project.md`。

## 共通

- 1動画に色は3つまで（背景・文字・アクセント）
- ブランド名とURLは最後の1.5秒に置く。冒頭に置くと本題が遅れる
- 複数ブランドの世界観を混ぜない（サブスクやめた／ライフオラクルは別ブランド運営が前提）
- 名前・URL が無いプロジェクトなら出さない（空欄の「 / 」を出さない）
