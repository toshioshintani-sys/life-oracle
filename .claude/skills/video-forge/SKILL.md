# 動画をつくる（Remotion）

動画は「情報を並べたスライド」ではない。**動きそのものが意味を運ぶ**。
このスキルの目的は、レンダリングを通すことではなく、**毎回ちがう動画**を作ること。

---

## 0. 発動したら最初にやること

**「何を伝えるか」ではなく「何が動くか」を先に決める。**

依頼文から次を確定させる（不明なものは仮決めして進める・全部聞き返さない）：

| 項目 | 既定値 |
|---|---|
| ブランド | 依頼の文脈から判定（`references/brand.md`） |
| 比率・解像度 | 縦型 1080×1920（note/リール）／正方形 1080×1080（X） |
| 尺 | 6秒（180f @30fps）。情報量が多ければ 8〜10秒まで |
| 音 | 無し（素材が指定された時のみ付ける） |

---

## 1. 禁止事項（該当したら作り直し）

これは好みの問題ではなく、**AIが放っておくと必ず作る型**なので構造的に禁ずる。

1. **中央寄せタイトル ＋ 箇条書きカード3枚 ＋ フェードイン** — 最も出やすい型。単体で使わない
2. **前に作った動画のレイアウト流用**（変えるのはテキストだけ、という作り方）
3. **意味のない装飾**：背景のふわふわした丸、パーティクル、意味なく回るグラデーション
4. **全要素が同じ方向・同じイージングで出てくる**（動きに階層がない＝目が滑る）
5. **文字が出るだけで、被写体が何も変化しない**（＝静止画のスライドショー）
6. **1フレーム目が空**（サムネ表示・自動再生オフの環境で死ぬ。0フレーム目から画が成立していること）

---

## 2. 手順

### Step 1 — コンセプトを3案出して1つ選ぶ

各案は**主役の動きが別物**であること（配色違い・文言違いは別案ではない）。1行ずつ書く。

> 例（「使ってないサブスクを1本やめる」）
> - A: 月額バーが積み上がり、1本を引き抜くと総額が崩れて減る（**主役＝数字の減少**）
> - B: 契約画面のスクロールが延々続き、「解約」ボタンだけが取り残される（**主役＝スクロール**）
> - C: 12個のアイコンが毎月コピーされて増殖し、1つ選ぶと連鎖が止まる（**主役＝増殖の停止**）

選定基準は「読者の頭の中で起きていることに一番近い動き」。**迷ったら数字か比喩が動く案を採る。**

### Step 2 — signature move を1つ決める

その動画にしかない一手。これが無い動画はテンプレになる。
（例：総額のカウントダウン／文字が契約書のように埋まる／画面が上下2層に割れて過去と未来を同時に見せる）

### Step 3 — 書く

`assets/kit/` を作業ディレクトリにコピーして使う（`references/kit.md` に起動手順）。
**`src/compositions/` に新しいファイルを新規で書く。既存 composition を上書き・流用しない。**
プリミティブ（`src/lib/motion.js`・`src/lib/text.jsx`）は使い回してよい — 使い回すのは *部品* であって *レイアウト* ではない。

### Step 4 — 目で見る（省略禁止）

```bash
node scripts/render.mjs --id=<CompId> --stills=0,45,90,135,179
```

出力された PNG を **Read ツールで実際に開いて見る**。見ずに「できました」と言わない。
チェック：①0フレーム目が成立しているか ②文字が画面外/重なり無しか ③動きの主役が一目でわかるか
④ブランド禁則（`references/brand.md`）に触れていないか。
**最低1周は直す。**一発で通ったと感じたら、それは見ていない。

### Step 5 — 書き出す

```bash
node scripts/render.mjs --id=<CompId> --out=out/<slug>.mp4
```

完成したら `SendUserFile` で俊雄さんに渡す。実測（解像度・尺・ファイルサイズ・所要秒）も報告する。

---

## 4. 越えてはいけない線

- **サブスクやめた**：煽り・ランキング・★スコアは禁止（憲法 §2-2）。動画でも同じ。
  「やめさせる」ではなく「やめた人が共有する」語り口。解約導線の信頼がアフィリエイトより常に強い。
- **ライフオラクル**：断定してラベルを貼らない。羅針盤モチーフはブランドシグネチャ。
- **新規依存**：kit は各サイトの `package.json` から独立している。サイト本体のビルドに Remotion を
  組み込むのは憲法 §5-D（新規依存導入）に該当するので、**その時は `stress-test` を通してから**。
- Remotion は OSS だが無償枠は個人・小規模まで（従業員4名以上は Company License）。
  法人化する時に再判断が要る。
